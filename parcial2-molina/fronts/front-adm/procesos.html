¿Qué hace este procedimiento?

Este proceso permite filtrar nuestro inventario aplicando una lógica de negocio específica para agrupar vehículos según su marca. Al ejecutarlo, el sistema consulta nuestra base de datos y retorna solo las unidades que coinciden con tu criterio de búsqueda.
